About

This portfolio highlights hands-on security labs with reproducible steps, evidence artifacts, and reflections on how findings translate to production hardening.

Each lab is designed to be cloned and run locally, with Docker Compose files, configuration snippets, and verification commands you can execute yourself. Evidence is captured through logs, packet traces, and screenshots so you can see exactly what changed when controls were applied.

Focus areas

Detection-first mindset

Instrumentation, query logging, and audit trails are prioritized to make defensive outcomes observable and reviewable.

Operational realism

Configurations mirror what you would run in production (e.g., DNSSEC validation, least-privilege defaults, TLS-by-default for apps).

Documented evidence

Every lab comes with commands, outputs, and screenshots to prove it worked, not just instructions that say it should.

Roles targeted
  • SOC Analyst — log review, packet analysis, and triage workflows.
  • Security Engineer — service hardening, secure defaults, and observability.
  • Network Security Analyst — DNS and traffic-layer controls validated with captures.
